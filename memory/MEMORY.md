## Standing project rules (always apply)
- **100% surface parity.** The browser WebPortal and the local Father Eye Panel (macOS desktop app) must always expose the same tabs and the same features, every time. Any tab or feature added to one surface must be added to the other in the same change. A feature is not considered done until it exists, with equivalent behavior, on both surfaces.
- **macOS deploy targets.** After a GitHub push, deploy the Forge bridge jar to `~/Desktop/Server/mods/fathereye-bridge-0.3.3-mac.1.jar` (replacing the same-named jar) and the desktop bundles to `/Applications/Father Eye.app` and `/Applications/Father Eye Setup.app`. The old Windows paths (`C:\Users\Luke\Desktop\Server\mods\`) were Chunky-pregen-only and are retired. Restart the server to load a new bridge jar.
